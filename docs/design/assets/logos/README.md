# Logos institucionais

Arquivos usados nas peças da feira.

O `banner-central.svg` já está com as duas logos **embutidas em base64**; os arquivos desta pasta são as fontes originais para edição.

## Arquivos

| Arquivo | Uso | Observação |
|---|---|---|
| `escudo-escola.jpg` | Arquivo original do escudo | Fundo preto; serve como fonte para a versão transparente |
| `escudo-escola.png` | Banner central, canto superior esquerdo | Versão com fundo transparente, usada no SVG. Se for usar o JPG, aplique `mix-blend-mode: screen` |
| `seduc-pi.png` | Banner central, canto superior direito | Logo da Secretaria da Educação / Governo do Piauí; usar em cartão branco para preservar o fundo |

## Regras de uso

- Usar sempre os arquivos oficiais, sem redesenhar.
- Não distorcer, não recortar e não alterar as cores.
- Preservar a proporção original.
- Manter uma área de respiro ao redor.
- Em caso de fundo escuro, usar a versão PNG transparente do escudo (preferencial) ou a mesclagem `screen` com o JPG.
- Em caso de fundo claro, usar a versão da SEDUC diretamente.
