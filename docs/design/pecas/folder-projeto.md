# Folder impresso por projeto

## Objetivo

Entregar ao visitante um resumo de bolso do projeto, com motivação, proposta, destaques e QR code. É a peça que continua com a pessoa depois da feira.

## Especificação

| Item | Valor |
|---|---|
| Formato aberto | A4 — 21 × 29,7 cm |
| Formato fechado | A5 — 14,8 × 21 cm |
| Páginas | 4 (frente e verso, dobrado) |
| Papel | Couché 250 g |
| Acabamento | Dobra central; opcional laminação fosca |
| Sangria | 3 mm |
| Margem de segurança | 8 mm |
| Quantidade sugerida | 50 a 100 por projeto |

### Alternativa econômica

Um flyer A5 frente e verso, sem dobra. Usa uma folha A4 cortada ao meio e reduz o custo.

## Estrutura (4 páginas)

```
┌─────────────────┬─────────────────┐
│  CAPA           │  MOTIVAÇÃO      │
│  nome do app    │  o problema     │
│  frase de       │  por que importa│
│  efeito         │                 │
│  ícone          │                 │
│  QR code        │                 │
├─────────────────┼─────────────────┤
│  PROPOSTA       │  FECHAMENTO     │
│  o que faz      │  destaques      │
│  3 recursos     │  tecnologias    │
│                 │  equipe + QR    │
└─────────────────┴─────────────────┘
```

## Conteúdo por página

### Capa
- Nome do app.
- Frase de efeito.
- Ícone grande.
- Cor principal do projeto.
- QR code para abrir o app.

### Motivação
- Título: "Por que criamos este projeto".
- Dois parágrafos curtos: o problema e quem é afetado.
- Uma frase de impacto.

### Proposta
- Título: "O que o app faz".
- Dois parágrafos curtos.
- Três recursos em lista com ícone.

### Fechamento
- Tecnologias em uma linha.
- Nome dos alunos, turma e escola.
- QR code repetido.
- Apoio do Marketing Digital.
- Aviso específico do projeto (quando houver).

## Tipografia

| Elemento | Tamanho |
|---|---|
| Nome do app (capa) | 40–48 pt |
| Frase de efeito | 18–22 pt |
| Títulos internos | 16–18 pt |
| Corpo | 11–12 pt |
| Rodapé e tecnologias | 8–9 pt |

## Cores

- Capa e página de fechamento na cor principal do app.
- Páginas internas em branco ou off-white.
- Títulos na cor do app.
- QR code sempre em fundo branco.

## Produção

1. Fechar os textos no `folder.md` do projeto.
2. Diagramar em A4 com a dobra no centro.
3. Marcar a linha de dobra (não imprimir marca visível).
4. Exportar PDF CMYK com 3 mm de sangria.
5. Pedir prova de cor.
6. Imprimir, dobrar e conferir o QR code.

## Distribuição

- Deixar uma pilha em cima da mesa de cada app.
- Entregar ao final do pitch.
- Usar como apoio para o professor visitante.
- Guardar alguns para a direção e para os parceiros.

## Referência

- Conteúdo preenchido: `folder.md` dentro do folder de cada projeto.
- Template visual: reaproveitar a lógica da [`cartolina descritiva`](./cartolina-descritiva.md), adaptando para A4 dobrado.
