# Bolsa Fácil

## Motivação

O cidadão comum ouve falar de Selic, CDI, ações e FIIs, mas raramente entende o que esses termos significam na prática. A informação está espalhada, cheia de jargão e muitas vezes acompanhada de promessas de enriquecimento rápido. O Bolsa Fácil traduz o mercado para quem está começando.

## Proposta

Um site educativo com painel de cotações e indicadores reais, trilhas curtas, glossário, comparador de investimentos, simulador de juros compostos, quiz e um curador de IA que explica tudo em linguagem simples — sempre com aviso de que não é recomendação.

## Público

- Estudantes do ensino médio e técnico
- Famílias de baixa e média renda
- Pessoas que estão começando a investir
- Visitantes da Feira das Profissões

## Mensagem-chave

**"Entenda o mercado. Sem economês."**

Frase de efeito para o estande: **"Seu primeiro investimento é entender."**

## Diferenciais

1. Dados reais de mercado (brapi + Banco Central).
2. Curador com IA que usa os dados do painel.
3. Simulador que mostra o efeito dos juros compostos.
4. Conteúdo com foco em prevenção a golpes.
