## Como usar

1. Leia a identidade visual antes de produzir qualquer peça.
2. Preencha os campos entre `[colchetes]` com data, local, nomes da equipe e links reais.
3. Use os arquivos SVG em `design/assets` como referência de layout.
4. Confira medidas e margens de segurança antes de enviar para a gráfica.
5. Imprima o checklist de montagem e leve para a escola.
